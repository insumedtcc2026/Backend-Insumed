Sobre esta documentação

Esta referência descreve as rotas registradas, os middlewares aplicados e as regras de negócio identificadas nos controllers/utilitários.

Base URL de produçãohttps://backend-insumed-lhac.vercel.app. O botão “Copiar método + URL” copia a URL de hospedagem da API. Exemplo, GET https://backend-insumed-lhac.vercel.app/pacientes.
FormatoJSON UTF-8 para operações comuns. Arquivos de prescrição podem ser entregues como conteúdo binário com Content-Type próprio.
AutenticaçãoJWT via Authorization: Bearer <token>, exceto rotas explicitamente públicas e a tarefa protegida por CRON_SECRET.
