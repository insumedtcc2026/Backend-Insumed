POST /login

Realiza a autenticação verificando, na ordem, as tabelas pacientes, autorizador e administrador (Login Unificado).

Corpo da Requisição (JSON):

{
  "email": "usuario@email.com",
  "senha": "suasenha123"
}

Respostas:

200 OK - Retorna o Token JWT e dados do usuário logado.
400 Bad Request 
{ "erro": "E-mail e senha são obrigatórios" }
401 Unauthorized 
{ "msg": "E-mail ou senha inválidos" }
GET /pacientes

Retorna todos os pacientes cadastrados no sistema.

Respostas:

200 OK - Array de objetos com todos os dados da tabela pacientes.
POST /pacientes

Cria um novo paciente. O sistema gera automaticamente um avatar baseado nas iniciais do nome.

Corpo da Requisição (JSON):

{
  "nome": "João da Silva",
  "email": "joao@email.com",
  "telefone": "(24) 99999-9999",
  "cpf": "123.456.789-00",
  "data_nasc": "1990-01-01",
  "sexo": "Masculino", 
  "endereco": "Rua A, 123",
  "raca": "Branca",
  "senha": "senha123",
  "cep": "12345-678"
}

Respostas:

201 Created 
{ "msg": "Usuário cadastrado com êxito" }
400 Bad Request - Erros de validação (Telefone, E-mail, CEP, CPF inválidos ou e-mail já cadastrado).
GET /pacientes/buscar

Busca pacientes pelo CPF. Formatação ignorada na busca.

Query Params:

?cpf=12345678900

Respostas:

200 OK - Array contendo até 10 resultados. 
[
  { 
    "pac_id": 1, 
    "pac_nome": "João", 
    "pac_cpf": "12345678900", 
    "pac_telefone": "..." 
  }
]
GET /agendamentos

Lista agendamentos com filtros avançados. (Visão do Administrador)

Query Params Disponíveis:

  • status: 'agendado', 'concluido', 'cancelado', 'todos'
  • busca: Nome, CPF ou Protocolo
  • data_inicio e data_fim: Formato YYYY-MM-DD
  • order: 'proximidade' ou 'asc'

Respostas:

200 OK - Array de agendamentos agrupados.
POST /agendamentos

Cria um novo agendamento, gera o protocolo e insere os itens de coleta via transação. (Visão do Administrador)

Corpo da Requisição (JSON):

{
  "paciente": { "pac_id": 1 },
  "sol_data_de_coleta": "2026-10-15",
  "posto": { "pos_id": 2 },
  "itens": [
    { "ins_nome": "Seringa", "quantidade": 2 },
    { "ins_nome": "Tubo de ensaio", "quantidade": 5 }
  ]
}

Respostas:

201 Created 
{ 
  "message": "Agendamento criado com sucesso", 
  "sol_id": 42, 
  "sol_protocolo": "AG000042" 
}
PATCH /agendamentos/:id/concluir

Atualiza o status do agendamento para concluído.

Respostas:

200 OK 
{ "message": "Agendamento concluído" }
404 Not Found 
{ "message": "Agendamento não encontrado" }
PATCH /agendamentos/:id/cancelar

Atualiza o status do agendamento para cancelado.

Respostas:

200 OK 
{ "message": "Agendamento cancelado" }
GET /agendamentos/meus

Retorna os agendamentos do paciente logado, com paginação. Exige token de Paciente.

Query Params:

?page=1&porPagina=4

Respostas:

200 OK 
{ 
  "itens": [...], 
  "paginaAtual": 1, 
  "totalPaginas": 3 
}
403 Forbidden 
{ "error": "Rota exclusiva de paciente" }
POST /solicitacoes

Envia uma nova solicitação/prescrição vinculada ao paciente logado.

Corpo da Requisição (JSON):

{
  "pos_id": 1,
  "sol_prescricao": "BASE_64_STRING_DA_IMAGEM",
  "sol_observacao": "Observação opcional",
  "sol_prescricao_tipo": "Tipo opcional"
}

Respostas:

201 Created 
{ "message": "Solicitação enviada com sucesso", "solicitacao": [...] }
POST /administradores

Cria um novo administrador no sistema.

Corpo da Requisição (JSON):

{
  "matricula": "ADM123",
  "nome": "Admin Silva",
  "email": "admin@email.com",
  "telefone": "24999999999",
  "senha": "senhaforte",
  "cpf": "12345678900",
  "posto_id": 1
}

Respostas:

201 Created 
{ 
  "message": "Administrador criado com sucesso", 
  "id": 1, 
  "tp_universal": false, 
  "vinculado_a_posto": 1 
}
GET /insumos/buscar

Busca insumos por nome ou ID (utilizado no momento de criar agendamentos).

Query Params:

?busca=seringa

Respostas:

200 OK 
[
  { 
    "ins_id": 1, 
    "ins_nome": "Seringa", 
    "ins_quantidade": 100 
  }
]
GET /postos

Retorna a lista de todos os postos de saúde cadastrados ordenados alfabeticamente.

Respostas:

200 OK - Array com dados de postos.
